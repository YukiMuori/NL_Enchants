## Effect

+1.0 block interaction range per level over the vanilla 4.5 (5.5 / 6.5 / 7.5). Valid in MAINHAND and OFFHAND — holding the tool in the offhand lets you place blocks at range too (vanilla reach governs placing as well).

## VFX

None (passive attribute).

## Notes

- Requires the MythicMobs Stats system (RUNTIME-VERIFY). Original spec: L2 extends Crab's Touch range for Gluttony — Gluttony is skipped, so no interaction exists.
