# Skipped from the AE Vanilla+ list

Per the project rules (R6: never invent syntax), these AE enchants are NOT
implemented — with the exact reason. Revisit when a supporting mechanic is
verified on the official wiki.

| AE Enchant | Reason |
| --- | --- |
| Abrasion | No verified mechanic to damage the TARGET's armor. |
| Alacrity | Duplicate of Haste (same effect) — merged. |
| Allurement, Fire Hook, Poisoned Hook, Sharpness Hook | No verified fishing trigger in MythicEnchants docs. |
| Ascend, Charge | Need right-click activation on melee items (~onUse semantics unverified for them). |
| Aura | Reducing OTHER players' damage events from my event is not possible with verified mechanics. |
| Brightness | Warden-only niche; trivial variant of the bane family if ever wanted. |
| Caffeinated | Conditional attack-speed attribute not verified. |
| Carve | AoE on swing would double-hit the main target (no hit-exclude without Premium targeter conditions). |
| Contagion | Location-persisting void cloud — unverified compound. |
| Criticals, Shura | No crit-event detection in verified mechanics. |
| Curse of Breaklessness / Harmlessness | No verified event-cancel mechanic. |
| Escape / Getaway | Getaway duplicates Escape (merged into Escape). |
| Fuddle | No hotbar manipulation mechanic. |
| Infernal Touch | No autosmelt mechanic. |
